Struct FastInput

pub struct FastInput {
    ptr: *const u8,
}
Expand description

Token reader for little-endian targets. Integer reads require a decimal representation that fits the requested type, with at most that type’s maximum number of digits and an optional - for signed types.

Each read must start at a token and consumes exactly one trailing ASCII whitespace byte. parse additionally requires UTF-8. bytes returns a slice whose lifetime must not exceed that of the input allocation.

On x86-64, enabling ssse3 at compile time selects SIMD for u64 tokens.

pub unsafe fn stdin() -> Self

Reads all of stdin and retains its storage until process exit.

§Safety

Call before any other stdin reads. A mapped input file must not be modified while its contents or slices returned by this reader are in use.

Source

pub unsafe fn from_slice(s: &[u8]) -> Self

§Safety

s must contain at least 16 initialized padding bytes after its final token delimiter. Its allocation must remain valid and unchanged while this reader or any slices returned by it are in use.
