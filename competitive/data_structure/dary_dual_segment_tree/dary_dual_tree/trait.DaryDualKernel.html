Expand description

SIMD blocks for range actions and point access, without aggregates.

B is a power of two greater than one. compose(old,later) preserves action order. Leaves retain all supplied keys; branch initializes B identity tags. Branches contain only child tags. Editing a block first applies carry to every valid lane, then action to full, then clears the tags of the boundary children in edges. Those children were already edited.

§Safety

ISA is 0 (portable), 1 (AVX2), or 2 (AVX-512F/DQ/CD/BW/VL), supported by the CPU. Kernels check any additional ISA requirements and support portable execution on other architectures. Unsafe methods receive len <= B and valid ranges/lanes.
