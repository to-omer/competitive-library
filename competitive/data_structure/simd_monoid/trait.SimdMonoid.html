Expand description

A monoid with a lane-wise implementation that can be shared by SIMD trees.

Implement this trait to use the operation directly in a d-ary segment tree. Commutative operations can also be used in a SIMD binary indexed tree.

unsafe fn operate_lanes<const ISA: u8>(lhs: &mut [Self::T], rhs: &[Self::T])

Replaces each left operand with its ordered product with the right operand.

§Safety

The slices have equal lengths. ISA 0 requests portable execution, ISA 1 guarantees x86-64 AVX2, and ISA 2 guarantees x86-64 AVX-512F/DQ/CD/BW/VL. Implementations support unaligned slices of any length, including tails, and check any additional CPU requirements themselves.

unsafe fn broadcast_suffix<const ISA: u8>( values: &mut [Self::T], start: usize, rhs: Self::T, )

Appends the same right operand to every lane from start onward.

§Safety

The ISA and alignment contracts are the same as for Self::operate_lanes. start must be at most values.len().

unsafe fn reduce_lanes<const ISA: u8>(values: &[Self::T]) -> Self::T

Folds the slice in order, returning the unit for an empty slice.

§Safety

The ISA contract is the same as for Self::operate_lanes. The slice has at most 16 values.
