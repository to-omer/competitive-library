Functions§

count_multiples_with_digits
Counts positive multiples of divisor up to upper that contain required and use at most max_distinct decimal digits. Leading padding zeros are ignored. Requires 1 <= divisor <= 100, max_distinct <= 10, and required < 10.
count_words_with_remainder
Counts length-len base-radix words whose value is remainder modulo divisor. Includes leading zeros and returns the count modulo 998244353. Requires 2 <= radix <= 10, 1 <= divisor <= 100, and remainder < divisor. Takes O(divisor^3 log len) time.
digit_sum_count_and_sum
Counts and sums integers in [lower, upper] whose base-radix digit sum is k. Requires 2 <= radix <= 10 and lower <= upper. Zero has digit sum 0.
digit_sum_queries
Counts words with digit sum k and selects a word for each (lower, upper, rank) query. Bounds contain base-radix digits, including leading zeros, with equal lengths at most len. Requires 2 <= radix <= 10. Counts saturate at u128::MAX; the zero-based rank must be smaller. Missing ranks return None. Precomputation takes O(len * (k + 1) * radix) time and O(len * (k + 1)) space.
