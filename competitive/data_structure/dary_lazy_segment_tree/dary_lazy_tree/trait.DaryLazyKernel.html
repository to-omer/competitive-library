Expand description

Block operations for an ordered d-ary lazy segment tree.

combine(left, right) preserves key order; compose(old, later) preserves action order. Change repairs a summary after its incoming carry has already been applied. A boundary repair consumes the child’s stored tag even when the summary does not change. None from constant means the old keys are needed.

B is a power of two greater than one. Leaves retain all supplied keys; blocks contain at most B valid lanes. len is the number of keys in the subtree, width the power-of-two nominal span of a child; the last child may be shorter. Updating a block materializes its carry on every valid lane, updates full, then repairs edges. Child updates happen before their parent block is edited. State belongs to one tree; Prepared must not borrow it or leave dangling tags. prepare can inspect branch storage before the update to reclaim records that no stored tag uses. finish runs after all edits and consumes Prepared.

§Safety

Unsafe methods receive a nonempty valid subtree and in-bounds lane ranges. Empty fold ranges must return unit. ISA is 0 (portable), 1 (AVX2), or 2 (AVX-512F/DQ/CD/BW/VL), selected on a supporting CPU. Additional instruction sets require the kernel’s own check. Implementations must support the portable path on non-x86 targets.
