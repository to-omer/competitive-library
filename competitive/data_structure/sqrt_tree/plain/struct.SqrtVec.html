pub struct SqrtVec<T> {
    inner: Buckets<T, ()>,
}
Expand description

A sequence with amortized O(sqrt(N)) insertion/removal and O(sqrt(N)) indexing. An individual insertion or removal can take O(N) when rebuilding.
