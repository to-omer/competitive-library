pub struct SqrtFoldVec<M>
where
    M: Monoid,
{
    inner: Buckets<M::T, FoldState<M, SequenceValue>>,
}
Expand description

A sequence with ordered range aggregation and no lazy updates. With O(1) monoid operations, folds and amortized updates take O(sqrt(N)).
