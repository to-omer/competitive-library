pub struct SqrtReversibleFoldVec<M>
where
    M: MapMonoid,
{
    inner: Buckets<M::Key, FoldState<M, SequenceValue, bool>>,
}
Expand description

A sequence with range reversal and aggregation, without lazy updates. With O(1) monoid operations and toggle, range reversal is amortized O(sqrt(N)).
