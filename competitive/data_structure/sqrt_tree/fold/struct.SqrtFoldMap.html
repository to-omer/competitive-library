pub struct SqrtFoldMap<K, M>
where
    M: Monoid,
{
    inner: Buckets<(K, M::T), FoldState<M, MapValue>>,
}
Expand description

An ordered map with value aggregation in key order and no lazy updates. Key lookup takes O(log N); folds and amortized updates take O(sqrt(N)) for O(1) monoid operations.
