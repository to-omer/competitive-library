Struct GameAnalyzer

pub struct GameAnalyzer<G = ()> {
    game: G,
}
Expand description

Owns a fixed game definition and reusable analysis caches. Move generators may collect statistics, but must keep the rules unchanged. Closure-based games must be finite and acyclic; detected cycles panic. Outcome queries stop exploring a position once a winning move is found. Use impartial_graph for Win/Draw/Lose analysis of cyclic graphs.

use competitive::algorithm::{GameAnalyzer, GameOutcome};
let mut nim = GameAnalyzer::new().impartial(|&n: &usize| 0..n);
assert_eq!(nim.grundy().eval(&3), 3);
assert_eq!(nim.sum().grundy().eval(&[3, 3]), 0);
assert_eq!(nim.misere().outcome().eval(&1), GameOutcome::Lose);
assert_eq!(nim.outcome().eval(&1), GameOutcome::Win);
assert_eq!(nim.grundy().verify(0..10, |&n| n as u64), None);
